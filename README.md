# Пульт охраны

Играбельный браузерный low-poly 3D-прототип симулятора охранного
предприятия. Игрок исследует посёлок, общается с жильцами, заключает
договоры и открывает пульт централизованного наблюдения.

## Запуск локально

Требуется Node.js 22.13 или новее.

```bash
npm install
npm run dev
```

После запуска откройте адрес, показанный в терминале.

## Статическая версия

```bash
npm run build:pages
npm run preview:pages
```

Статические файлы создаются в `pages-dist`. Сборка настроена для адреса
`/Tranyaks/`.

## Публикация

Workflow `.github/workflows/pages.yml` автоматически собирает и публикует
игру в GitHub Pages после каждого изменения ветки `main`. Для первой
публикации выберите в репозитории:

1. **Settings → Pages**.
2. В разделе **Build and deployment** установите **Source: GitHub Actions**.
3. Объедините изменения с веткой `main` или вручную запустите workflow
   **Publish game to GitHub Pages** во вкладке **Actions**.

После успешной публикации игра будет доступна по адресу:

<https://abovetranyaks.github.io/Tranyaks/>

## Управление

- `W` — вперёд, `S` — назад, `A`/`D` — влево/вправо. Используются физические клавиши, поэтому управление одинаково работает в русской и английской раскладке.
- Двойное нажатие `W` — быстрый шаг; `Shift` — бег трусцой, пока хватает энергии.
- `E` — разговор с жителем, посадка в автомобиль и выход.
- `Space` — ручной тормоз автомобиля.
- `H` — клаксон.
- `Tab` — полноэкранная интерактивная карта.
- `P` — планшет с заданиями, договорами, филиалами, автопарком, профилем и сохранениями.
- `Esc` — пауза; из меню паузы доступно ручное сохранение.
- Правая кнопка мыши — свободный осмотр пешком и в автомобиле; после отпускания автомобильная камера мягко возвращается назад.

Игровой мир включает 100 low-poly домов в четырёх развивающихся районах между селом Первореченским и станицей Динской. Световой день длится два реальных часа, ночь — 15 минут.
На полноэкранной карте отображаются герой, автомобиль, клиентские дома, квестовые цели, типы дорог, ключевые точки, пользовательские заметки и маршрут. Миникарта мгновенно следует за игроком и показывает объекты в радиусе 80 метров.

В текущей версии также работают:

- четыре комплекта одежды с небольшими игровыми бонусами, покупкой и сохранением;
- пультовая, кабинет менеджера, комната отдыха, склад и гараж;
- кофе, отдых, обучение, пополнение оборудования и улучшение двигателя;
- ясная, облачная, дождливая и грозовая погода, закаты, звёзды и ночное освещение;
- разное сцепление автомобиля на асфальте, грунте и траве, ручной тормоз, занос, топливо и износ.
- журнал сюжетных, побочных, динамических и ежедневных заданий с целями, наградами, отслеживанием на HUD и метками на карте;
- побочные задания предлагаются в диалогах, а цели вне радиуса миникарты отмечаются направляющей стрелкой;
- миникарта переключается между вращением за героем и режимом «север сверху»;
- тревоги получают случайный сценарий, тарифный таймер, цепочку датчиков, историю объекта и разные последствия решений;
- новые жилые и коммерческие договоры, четыре филиала, найм диспетчеров, ГБР, техников и менеджеров;
- месячный баланс с абонентской платой, арендой, зарплатами, страховкой и кредитами под 10%;
- автосалон с новыми и подержанными автомобилями, выбором активной машины и разными характеристиками;
- полный сброс прогресса до 15 000 ₽, базовой одежды и стартового седана при сохранении локального профиля.
- четыре ежедневных испытания, обновляемых по реальному календарю, награды за серию входов и отслеживание на HUD;
- кооперативное лобби до четырёх игроков, текстовый чат и синхронизация персонажей, договоров, тревог, времени и погоды.

В статической версии кооператив использует `BroadcastChannel` и предназначен
для проверки между вкладками одного браузера. Интерфейс и сообщения сетевого
слоя подготовлены для замены транспорта на Photon/WebSocket при подключении
внешнего облачного сервера.

## Расширенная экономика

- Районы открываются по прогрессии, а офисы требуют аренды, персонала и ежемесячных расходов.
- Автосалон предлагает новые и подержанные машины по отдельным ценам; доступен trade-in.
- Автосервис учитывает топливо, износ, мойку, сезонные шины и установку мигалки.
- В магазинах можно приобрести батарейки, инструменты, литературу, еду и рекламные кампании.
- Чистый автомобиль и Toyota Camry дают небольшой бонус доверия в переговорах; рекомендации подписанных соседей повышают интерес ближайших жильцов.
- Менеджеры продаж при закрытии месяца приводят новые заявки из уже открытых районов.
