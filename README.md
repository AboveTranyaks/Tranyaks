# Пульт охраны

Играбельный браузерный low-poly 3D-прототип симулятора охранного
предприятия. Игрок исследует посёлок, общается с жильцами, заключает
договоры и открывает пульт централизованного наблюдения.

## Запуск локально

Требуется Node.js 22.13 или новее.

```bash
npm install
npm run dev
```

После запуска откройте адрес, показанный в терминале.

## Статическая версия

```bash
npm run build:pages
npm run preview:pages
```

Статические файлы создаются в `pages-dist`. Сборка настроена для адреса
`/Tranyaks/`.

## Публикация

Workflow `.github/workflows/pages.yml` автоматически собирает и публикует
игру в GitHub Pages после каждого изменения ветки `main`. Для первой
публикации выберите в репозитории:

1. **Settings → Pages**.
2. В разделе **Build and deployment** установите **Source: GitHub Actions**.
3. Объедините изменения с веткой `main` или вручную запустите workflow
   **Publish game to GitHub Pages** во вкладке **Actions**.

После успешной публикации игра будет доступна по адресу:

<https://abovetranyaks.github.io/Tranyaks/>

## Управление

- `W` — вперёд, `S` — назад, `A`/`D` — влево/вправо. Используются физические клавиши, поэтому управление одинаково работает в русской и английской раскладке.
- Двойное нажатие `W` — быстрый шаг; `Shift` — бег трусцой, пока хватает энергии.
- `E` — разговор с жителем, посадка в автомобиль и выход.
- `Space` — ручной тормоз автомобиля.
- `H` — клаксон.
- `Tab` — полноэкранная интерактивная карта.
- `P` — планшет с профилем, статистикой, рейтингом и сохранениями.
- `Esc` — пауза; из меню паузы доступно ручное сохранение.
- Правая кнопка мыши — свободный осмотр пешком и в автомобиле; после отпускания автомобильная камера мягко возвращается назад.

Игровой мир включает 100 low-poly домов в Первореченском и станице Динской, соединённых четырёхкилометровой дорогой. Световой день длится два реальных часа, ночь — 15 минут.
На полноэкранной карте отображаются герой, автомобиль, клиентские дома, типы дорог, ключевые точки, пользовательские заметки и маршрут. В планшете доступны локальный профиль, приватность, статистика, достижения, автономный рейтинг, 3 ручных слота и отдельное автосохранение.

В текущей версии также работают:

- четыре комплекта одежды с небольшими игровыми бонусами, покупкой и сохранением;
- пультовая, кабинет менеджера, комната отдыха, склад и гараж;
- кофе, отдых, обучение, пополнение оборудования и улучшение двигателя;
- ясная, облачная, дождливая и грозовая погода, закаты, звёзды и ночное освещение;
- разное сцепление автомобиля на асфальте, грунте и траве, ручной тормоз, занос, топливо и износ.
